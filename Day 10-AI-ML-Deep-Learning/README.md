# AI vs ML vs Deep Learning

## Day 10 - AI & ML Internship Task

This project explains the differences between Artificial Intelligence (AI), Machine Learning (ML), and Deep Learning (DL).

## Objective

To understand:

- What is Artificial Intelligence?
- What is Machine Learning?
- What is Deep Learning?
- How AI, ML, and DL are related
- Real-world applications of each technology

## Comparison

| Feature | AI | ML | Deep Learning |
|---|---|---|---|
| Meaning | Broad field of creating intelligent machines | Subset of AI that learns from data | Subset of ML using neural networks |
| Data | May use data and rules | Learns from data | Usually requires large datasets |
| Learning | Rules and learning methods | Learns patterns from data | Learns complex patterns using multiple layers |
| Examples | Virtual assistants, robots | Recommendations, spam detection | Face recognition, speech recognition |

## Relationship

**Artificial Intelligence → Machine Learning → Deep Learning**

Deep Learning is a subset of Machine Learning, and Machine Learning is a subset of Artificial Intelligence.

## Real-World Applications

### AI

- Automated decision-making

### ML
- Spam detection
- Recommendation systems
- Fraud detection
- Price prediction

### Deep Learning
- Face recognition
- Speech recognition

## Conclusion

AI is the broad field of creating intelligent systems. Machine Learning allows systems to learn from data, while Deep Learning uses multi-layer neural networks to solve complex problems. Understanding these concepts provides a strong foundation for learning AI and Machine Learning.
