# Day 11 – Number Statistics using NumPy

## Objective

The objective of this task is to use NumPy to analyze student marks and calculate important statistical values.

## Dataset

The dataset contains marks of 10 students:

`78, 85, 92, 67, 88, 74, 95, 81, 69, 90`

## Statistics Calculated

- Mean: 81.9
- Median: 83.0
- Maximum: 95
- Minimum: 67
- Standard Deviation: 9.33

## Tools Used

- Python
- NumPy
- Jupyter Notebook

## Learning Outcome

This task helped me understand how NumPy can be used to perform statistical calculations efficiently. I learned how to calculate mean, median, maximum, minimum, and standard deviation of a dataset.s
