# Day 12 – NumPy Array Operations

## Objective

The objective of this task is to understand basic mathematical operations on NumPy arrays and learn about vectorized operations.

## Operations Performed

Two NumPy arrays were created and the following operations were performed:

- Addition
- Subtraction
- Multiplication
- Division
- Shape checking

## Arrays Used

Array 1:

`[10, 20, 30, 40, 50]`

Array 2:

`[2, 4, 5, 8, 10]`

## Results

- Addition: `[12, 24, 35, 48, 60]`
- Subtraction: `[8, 16, 25, 32, 40]`
- Multiplication: `[20, 80, 150, 320, 500]`
- Division: `[5.0, 5.0, 6.0, 5.0, 5.0]`
- Shape of Array 1: `(5,)`
- Shape of Array 2: `(5,)`

## Technologies Used

- Python
- NumPy
- Jupyter Notebook

## Learning Outcome

This task helped me understand NumPy array operations, array shapes, and vectorization. I learned how NumPy makes numerical calculations simpler and more efficient.
