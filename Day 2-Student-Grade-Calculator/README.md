# Student Grade Calculator

## Day 2 - AI & ML Internship Task

This project is a simple Python program that calculates the grade of students based on their marks.

## Objective

To create a Python program that:
- Takes student marks
- Assigns a grade based on marks
- Displays the student's name, marks, and grade

## Grading Criteria

| Marks | Grade |
|------|------|
| 90 - 100 | A+ |
| 80 - 89 | A |
| 70 - 79 | B |
| 60 - 69 | C |
| 50 - 59 | D |
| Below 50 | F |

## Technologies Used

- Python
- Jupyter Notebook

## Sample Output

- Swetha: 85 → Grade A
- Rahul: 72 → Grade B
- Priya: 91 → Grade A+
- Arjun: 64 → Grade C
- Anjali: 48 → Grade F

## Conclusion

The Student Grade Calculator successfully assigns grades based on students' marks using Python conditional statements.
