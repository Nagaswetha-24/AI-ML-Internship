# Employee Salary Analysis

## Day 3 - AI & ML Internship Task

This project analyzes employee salary data using Python.

## Objective

To create a Python program that:
- Stores employee salary data
- Calculates the total salary
- Calculates the average salary
- Finds the highest salary
- Finds the lowest salary
- Compares the calculated results with the original salary data

## Salary Data

The program uses salary data for 10 employees.

## Results

| Analysis | Result |
|---|---:|
| Number of Employees | 10 |
| Total Salary | 386000 |
| Average Salary | 38600 |
| Highest Salary | 60000 |
| Lowest Salary | 25000 |

## Technologies Used

- Python
- Jupyter Notebook

## Conclusion

The Employee Salary Analysis program successfully calculates and displays important salary statistics using Python.
