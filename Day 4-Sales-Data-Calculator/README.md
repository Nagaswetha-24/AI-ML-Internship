# Sales Data Calculator

## Day 4 - AI & ML Internship Task

This project analyzes sales data using Python.

## Objective

To create a Python program that:
- Stores sales data
- Calculates total sales
- Calculates average sales
- Finds the highest sale
- Finds the lowest sale

## Sales Data

The program analyzes 10 sales records.

## Results

| Analysis | Result |
|---|---:|
| Number of Sales Records | 10 |
| Total Sales | 177500 |
| Average Sales | 17750 |
| Highest Sale | 28000 |
| Lowest Sale | 12000 |

## Technologies Used

- Python
- Jupyter Notebook

## Conclusion

The Sales Data Calculator successfully analyzes sales data and calculates important sales statistics using Python.
