# Number Statistics

## Day 5 - AI & ML Internship Task

This project analyzes a list of numbers using Python.

## Objective

To create a Python program that:

- Identifies even numbers
- Identifies odd numbers
- Finds the largest number
- Finds the smallest number

## Number Data

The program uses the following numbers:

12, 7, 25, 18, 30, 9, 42, 15, 6, 21

## Results

| Analysis | Result |
|---|---|
| Even Numbers | 12, 18, 30, 42, 6 |
| Odd Numbers | 7, 25, 9, 15, 21 |
| Largest Number | 42 |
| Smallest Number | 6 |

## Concepts Used

- Python Lists
- For Loop
- If-Else Statements
- Modulo Operator (%)
- `max()` function
- `min()` function

## Technologies Used

- Python
- Jupyter Notebook

## Conclusion

The Number Statistics program successfully identifies even and odd numbers and calculates the largest and smallest numbers using Python.
