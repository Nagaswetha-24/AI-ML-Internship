# Simple Data Filtering

## Day 8 - AI & ML Internship Task

This project demonstrates simple data filtering using Python.

## Objective

To create a Python program that:

- Stores student records
- Filters students based on marks
- Filters students based on department
- Applies multiple conditions together

## Student Data

The program contains student information including:

- Name
- Marks
- Age
- Department

## Filtering Conditions

### Condition 1
Students with marks **80 or above**.

### Condition 2
Students belonging to the **CSE department**.

### Multiple Conditions
Students who are from the **CSE department AND have marks 80 or above**.

## Concepts Used

- Python Lists
- Dictionaries
- For Loop
- If Statement
- `and` operator
- Data Filtering

## Technologies Used

- Python
- Jupyter Notebook

## Conclusion

The Simple Data Filtering program successfully filters student records using different conditions and demonstrates basic data handling and filtering in Python.
