# Python Data Processing

## Day 9 - AI & ML Internship Task

This project demonstrates basic data processing and analysis using Python.

## Objective

To create a Python program that:

- Stores student records
- Calculates summary statistics
- Processes records using a function
- Filters students based on their marks

## Student Data

The program contains student records with:

- Name
- Department
- Marks

## Summary Statistics

| Analysis | Result |
|---|---:|
| Number of Students | 5 |
| Total Marks | 390 |
| Average Marks | 78.0 |
| Highest Marks | 91 |
| Lowest Marks | 64 |

## Processing

Each student record is processed using a Python function to determine whether the student has passed.

## Filtering

Students with marks **80 or above** are filtered from the records.
